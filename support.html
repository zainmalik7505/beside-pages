Support

Need help with Beside?

We want Beside to feel calm, reliable, and easy to use. If you are running into a problem, need help with an import, or want to share feedback, we are here to help.

Contact support

Email us at zainworkmaill@gmail.com

Please include your device type, iOS version, app version, and a short description of the issue.

Common requests

  • App crashes or startup issues
  • Import or scan problems
  • Missing or damaged saved items
  • Questions about app behavior or privacy
  • Feedback or feature suggestions
Tip: before contacting support, please check that you are using the latest version of Beside from the App Store. If the issue is tied to a specific document, file, or note, including the relevant file name and a brief description will help us investigate faster.
